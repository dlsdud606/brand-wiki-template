## 근거 자료의 성격

| 자료 | 성격 | 이 문서에서 쓰는 곳 |
|---|---|---|
| `raw/design/[사이트 실측]` | 공식 사이트 화면의 계산된 스타일을 코드에서 읽은 실측. 캡처에서 짐작한 값은 「근삿값」 | 로고·컬러·타이포·그리드 |
| `raw/design/[BI 가이드 또는 시각 기준]` | | |
| `raw/design/[캐릭터 기준]` | | 캐릭터 절 |

사이트 실측은 캡처 이미지가 아니라 실제 주소를 AI에게 읽힌다(Aside 브라우저 등). 코드에서 읽은 값은 「실측」, 화면을 보고 짐작한 값은 「근삿값」으로 표시하고, 결과 문서의 「제안」을 브랜드 공식 규정처럼 옮기지 않는다.

사용자 지정으로 마루 부리 SemiBold·배민 주아체 Regular·Gmarket Sans Bold를 추가한다. 실제 TTF·설치 방법·용도·릴스 설정은 [콘텐츠용 서체](fonts.md), 근거는 `raw/design/fonts/sources.json`과 라이선스 원문에 있다. 이 목록은 신규 제작용 선택지이며 원본 자산의 서체 식별 결과는 아니다. 기존 BI 지정 서체가 있으면 우선한다.
