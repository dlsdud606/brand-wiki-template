# 위키 승격 규칙

> 용도: `deliverables/`의 지식을 `01_knowledge/`로 올릴 때의 판정 기준(R6). 승격은 사람이 한다.

## 5필터

1개 이상 충족 + 사람 승인. 다섯 필터 전부에 답을 적어 둔다.

| 필터 | 묻는 질문 | 통과 예 | 탈락 예 |
|---|---|---|---|
| ① 재사용성 | 다른 콘텐츠에 또 쓰일 지식인가 | | 한시 메시지 |
| ② 근거 확실성 | 출처를 열어 확인했는가 | | 전언, 추정치 |
| ③ 시효성 | 언제까지 유효한가를 적을 수 있는가 | | 프로모션 가격 |
| ④ 브랜드 정합성 | 톤 원칙·표기 규칙과 맞는가 | | 금지 표현이 든 카피 |
| ⑤ 민감정보 없음 | 개인정보·미공개 자료가 없는가 | | 이름·연락처, 내부 매출 |

## 무엇이 어디로 가는가

| 승격 대상 | 받는 문서 |
|---|---|
| 확인된 표현 | `approved-claims.md` 승인 표 |
| 검수 통과·성과 확인 카피 | `proven-content.md`, 필러 대표 헤드라인 |
| 반려 카피와 사유 | `forbidden-expressions.md` 고쳐야 할 예문 |
| 새 소비자 표현·저항 신호 | `voc-insights.md` |
| 경쟁사 변화 | `competitors.md` |
| 확정 비주얼 규칙 | `visual-guidelines.md` |
| 새 원천 자료 | `raw/` (출처·수집일 표기) |

## 절차

1. 승격 후보 표: `후보 | 근거 경로 | 5필터 판정 | 받는 문서`
2. 사람이 출처 확인·승인. Plan 먼저
3. 근거 경로·수집일을 붙여 반영. 승인 표면 ID·승인자·일자·유효기간
4. 점검 실행
5. 작업 기록에 남김

## 승격 제외 대상

- 후보 표(`R-xx`) 자체
- 한 번의 관찰값
- 표본의 비율
- 성과 지표 없는 카피
