# 사람 개입 스위치표

> 용도: 파이프라인 단계마다 **자동 / 사람 승인 / 사람만** 중 하나를 정한 조직 기준. 모든 행에 하나만 체크하고 이유를 적는다.
> 자동: 사람이 보지 않아도 진행, 결과만 로그. 사람 승인: AI가 만들고 사람이 통과시켜야 다음으로. 사람만: AI가 하지 않는다.

| 단계 | 자동 | 사람 승인 | 사람만 | 담당 | 이유 |
|---|:---:|:---:|:---:|---|---|
| 캠페인 브리프 작성 | | | | | |
| 입력 준비 | | | | | |
| 근거 팩 작성 | | | | | |
| 후보 `R-xx` → 승인 `C-xx` | | | | | |
| 카피 초안 작성 | | | | | |
| 앵글 선택·확정 | | | | | |
| 비주얼 브리프 | | | | | |
| 이미지·영상 생성 | | | | | |
| 자동 검수 판정 | | | | | |
| FAIL 초안 수정 (1회) | | | | | |
| 2연속 FAIL 이후 처리 | | | | | |
| PASS 초안의 채택 | | | | | |
| 위키 승격 | | | | | |
| 발행·광고 집행 | | | | | |
| 비용·로그 점검 | | | | | |

## 사람이 멈추는 지점

| 지점 | 언제 | 보는 것 | 결정하는 것 |
|---|---|---|---|
| ⓐ 입력 확인 | 실행 전 | | |
| ⓑ 검수 FAIL 정지 | FAIL 2연속 | | |
| ⓒ PASS 후 승인 | 정상 실행 후 | | |
| ⓓ 회수·발행 결정 | 승인 뒤 | | |

## 조정 기준

- 완전 자동으로 발행까지 가는 콘텐츠는 두지 않는다
- 자동화가 멈추면 프롬프트가 아니라 입력·위키를 먼저 본다
- 스위치를 「자동」으로 옮길 때는 그 단계의 실패가 어디서 잡히는지 함께 적는다
