# 발행 전 최종 검수 체크리스트

> 용도: 자동 검수가 PASS를 낸 초안을 사람이 발행 직전에 확인하는 표. 하나라도 통과하지 못하면 발행하지 않는다.

## 1. 근거

- [ ] 효능·운영 표현마다 `[근거: C-xx]`가 있고 승인 표에서 확인했다
- [ ] 사양 문장마다 `[근거: 제품 정보]`가 있고 제품 마스터와 대조했다
- [ ] `[확인 필요]` 값이 사실처럼 들어가지 않았다
- [ ] [확인되지 않은 값 유형]이 없다
- [ ] 인용 리뷰는 원문과 같고 「소비자 리뷰 기준」이 붙어 있다

## 2. 심의·법

- [ ] [법규 기준 전량 금지 분류] 없음
- [ ] 최상급은 조건을 지켰다
- [ ] 인증·원료가 효과로 넓혀지지 않았다
- [ ] 레퍼런스의 문장·이미지·로고·서체를 가져오지 않았다
- [ ] 실제 인물 사진·개인정보 없음
- [ ] 생성 이미지 고지 있음

## 3. 브랜드

- [ ] [어미·이모지·느낌표]
- [ ] [호칭]
- [ ] [표기 규칙]
- [ ] 첫 문장이 [정한 출발점]에서 시작한다
- [ ] 사양이 표에 있다
- [ ] CTA 한 개, 허용 형태
- [ ] 경쟁사 실명·비교 우위 없음

## 4. 채널

- [ ] 채널 가이드의 길이·형식·규격
- [ ] 표·수치·FAQ가 텍스트로
- [ ] 링크가 실제 페이지로 연결

## 5. 브리프 대조

- [ ] 브리프의 목표·타깃·필러·제품·근거 ID와 산출물이 맞는다
- [ ] 반영·누락 항목 표를 받아 봤다

## 6. 발행 후

- [ ] 발행본을 `deliverables/content/<건명>/05_최종/`에
- [ ] 버린 시안은 `99_폐기/`에
- [ ] 승격 후보를 적었다
- [ ] 브리프의 「결과 기록」을 채웠다
