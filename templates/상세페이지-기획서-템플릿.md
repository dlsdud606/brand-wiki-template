# 상세페이지 기획서 · (제품명)

> 이미지 프롬프트와 HTML 조립이 이 파일을 읽는다. 섹션 수 · 순서 · 말투는 정해 두지 않는다. 숫자와 라벨 문구만 제품 사실 파일의 값을 쓴다.
> 작성 팀 / 작성자 :
> 제품 (공식 판매 페이지의 실제 상품 1개) :
> 공개 페이지 확인일 :
> 판 : 창작형 (세 파일 · 주제 한 줄) / 실험 구조 (여섯 단계) / 실험 레퍼런스 (기법 하나) / 실험 후기 (고객의 말) / 최종 (섞음) — 하나에 표시
> 근거 파일 : 제품 사실 파일 · 고객 정보 파일 · 후기_고객언어.md · 무드보드 (모두 기획서와 같은 폴더)
