# 캠페인 브리프 서식

> 용도: 캠페인 하나를 시작할 때 사람이 먼저 쓰는 문서. 릴레이·자동 실행은 이 문서를 읽고 무엇을 조사하고 무엇을 만들지 정한다.
> 저장 위치: `deliverables/content/[건명]/00_브리프.md`. 종료 후 결과 기록까지 채우고, 재사용할 카피·근거는 5필터로 `01_knowledge/`에 승격한다.

```markdown
# 캠페인: [캠페인명]  (기간: YYYY.MM.DD ~ YYYY.MM.DD)

## 목표
- 목적: 인지 / 전환 / 재구매 중 하나
- 핵심 KPI: [예: 상세페이지 전환율 3% → 4%]

## 대상
- 타깃: personas.md의 [페르소나] 또는 voc-insights.md의 [앵글]
- 콘텐츠 필러: key-messages.md의 [필러 번호]
- 대상 제품: product-lines.md의 [제품명]
- 쓸 수 있는 근거: approved-claims.md의 [C-xx, C-xx]

## 채널과 소재
| 채널 | 규격 | 우선순위 | 수량 |
|---|---|---|---|
| | | | |

## 이번 캠페인만의 메시지
- [한시적 메시지] (종료일: , 근거: C-xx 또는 신규 승인 필요)

## 조사 요청 (리서치 단계용)
- [알고 싶은 것 1]
- [알고 싶은 것 2]

## 결과 기록 (캠페인 종료 후)
- 성과:
- proven-content.md·필러 대표 헤드라인으로 옮긴 카피:
- forbidden-expressions.md 고쳐야 할 예문으로 옮긴 반려 카피:
- approved-claims.md에 새로 승인한 항목:
```

## 쓰는 법

1. 조사 요청은 구체적으로 적는다. 「경쟁사 분석해 줘」보다 「경쟁 A·B의 현재 판매가와 최근 3개월 프로모션, 30대 고객 리뷰에서 반복되는 불만 표현」이 결과를 쓸 만하게 만든다.
2. 쓸 수 있는 근거 칸에는 승인 표의 ID만 적는다. 승인되지 않은 표현을 쓰려면 먼저 근거 후보를 조사 요청에 올린다.
3. 채널 규격은 집행 채널의 현행 규격을 확인해 고쳐 쓴다.
4. 종료 후 결과 기록을 채우는 것까지가 캠페인이다.
