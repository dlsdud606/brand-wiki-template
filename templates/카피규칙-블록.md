# 카피 규칙 블록: 콘텐츠 파일 상단에 붙여넣는 주석

> 용도: 랜딩·상세페이지·카드뉴스 등 **콘텐츠 파일 맨 위에 이 블록을 붙여넣는다.** 대화창에서 매번 말하면 잊히지만, 파일에 적어두면 AI가 그 파일을 읽을 때마다 지킨다.
> 근거: `01_knowledge/negative-list/forbidden-expressions.md`. 아래 `[ ]`를 자기 브랜드 값으로 채운다.

## 블록 (채워서 복사)

```
// 카피 규칙 — 이 파일의 모든 문장은 아래를 지킨다
//
//  · 톤 3원칙:
//      [원칙 1] / [원칙 2] / [원칙 3]
//  · 말투:  [어미].  이모지 [0],  느낌표 [0]. 한 문장 [N]자 이내 권장.
//
//  · 전량 금지:
//      [법규 금지 분류 1]      ([예시 …])
//      [법규 금지 분류 2]      ([예시 …])
//      안전·효과 단정           (100% · 무조건 · 걱정 없음 …)
//
//  · 조건부 금지:
//      최상급            (최고 · 1위 · 유일 · 최초 …)
//        └ 예외: 승인 표에 등록된 수상·인증을 주최·연도·출처 병기 시
//
//  · 원칙:  효능이 아니라 '설계와 사실'을 말한다.
//           숫자를 쓸 때는 근거 ID를 함께 적는다.
//           확인 안 된 사실은 [확인 필요]로 표시하고 쓰지 않는다.
//           리뷰 평가는 "소비자 리뷰 기준"을 문장 안에 붙인다.
```

## 사용법

1. 콘텐츠 파일 맨 위에 블록을 붙여넣는다
2. 「이 규칙을 지켜 카피를 다시 써줘」로 재생성한다
3. 규칙 블록이 있는 파일과 없는 파일에서 같은 요청의 결과를 비교한다

> 같은 사상의 세 사례: CLAUDE.md(글의 일관성) → 디자인 기준서(비주얼의 일관성) → 이 블록(심의의 일관성). 규칙은 대화가 아니라 파일에 산다.
