# deliverables: 검토 전 초안 보관소

- 에이전트가 만든 결과물은 전부 여기에 먼저 저장된다. `research/`는 근거 팩·리포트, `content/`는 카피·카드뉴스·랜딩
- `01_knowledge/` 반영은 5필터(`04_human-review/promotion-rules.md`) 중 1개 이상 충족 + 사람 승인 시에만
- 파일명 규칙: `a1-주제.md`, `weekly-YYMMDD.md`처럼 코드·날짜를 앞에
- 근거·표현 후보는 리포트 안의 후보 표(`R-xx`)에 둔다. 승인 표(`C-xx`)로 옮기는 것은 사람의 승인 절차다
- 콘텐츠 건별 폴더 구조: `content/<건명>/00_브리프 · 01_근거 · 02_카피 · 03_비주얼 · 04_합성 · 05_최종 · 99_폐기`
