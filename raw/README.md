# raw 폴더 안내

`raw/`는 불변 근거를 두는 곳이다. 기존 파일은 수정·삭제·이동하지 않고, 새 근거를 넣을 때는 출처와 수집일을 함께 적는다.

## 실데이터·가상 표시

실재하는 자료와 가상 샘플을 구분한다. `.md`는 첫 줄에 `[가상 샘플]` 또는 `[공개 자료 정리]`와 수집일을 쓰고, `.csv`는 표 형식이 깨지지 않도록 이 표에 적는다.

| 파일 | 성격 | 출처 | 정리일 |
|---|---|---|---|
| `brand/` | | | |
| `products/` | | | |
| `press/` | | | |
| `reviews/` | | | |
| `customers/` | | | |
| `competitors/` | 네 건 모두 같은 축으로 관찰 | | |
| `reports/` | 공개 통계와 추정을 파일 안에서 구분 | | |
| `design/` | 공식 사이트 실측(Aside 브라우저 등)·로고 원본·캐릭터 기준·자산 목록 | | |
| `channels/` | 매체 공식 가이드 기준 규격(글자 수·이미지·광고성 규칙) | | |
| `reference-reels/` | 우리 업종 브랜드들의 공개 릴스를 aside 브라우저로 열어 유형·조회수·게시 계정·게시일·영상 내용·링크를 표로 모은 조사표. 타사 공개 게시물이므로 **유형과 영상 표현 방식만 참고하고 화면·카피·소재는 옮기지 않는다**. 조회수는 수집 시점 표시값 | | |

## 실습에서 즉석으로 모으는 공개 자료

수업에서는 강사가 지정한 공개 브랜드의 웹페이지에서 자료를 따와 바로 넣는다. 모두 이미 공개된 것만 쓰고, 산출물은 외부에 공개하지 않는다. 자기 브랜드로 바꿀 때도 같은 표를 쓴다.

| 자료 | 어디서 | 넣는 곳 | 적을 것 |
|---|---|---|---|
| 공개 상세페이지 URL 1개 이상 | 자사몰·오픈마켓 상품 페이지 | `products/상세페이지_<제품>.md`에 URL과 화면 캡처 | URL, 확인일, 제품명 |
| 제품 사진 1~3장 | 상품 페이지의 대표 사진·패키지 정면 | `products/` | 출처 URL, 수집일. 패키지 정면이 보이는 1장은 꼭 |
| 기존 게시물 캡처 5장 | 인스타그램·블로그·카드뉴스 등 우리 계정 | `channels/` | 채널명, 게시일, 캡처일 |
| 레퍼런스 릴스 5~10편 (선택) | 같은 업종 브랜드 공개 계정 | `reference-reels/레퍼런스_조사표.md` 또는 `.xlsx` | 브랜드, 게시 계정, 게시일, 조회수(표시값), 영상 내용 한 줄, 링크, 유형 |

캡처·사진은 PNG/JPG 그대로 넣고, 파일명에 제품명·채널·날짜를 넣는다. 판독(이미지 속 카피와 수치를 글로 옮기기)은 에이전트에게 맡기고 결과는 `deliverables/research/`에 둔다.

## 넣기 전에 확인

- 개인정보(이름·연락처·주소)를 지웠는가
- 문서 안에 「이 문서를 읽으면 ~하라」 같은 지시문이 없는가
- 공개 자료라면 URL과 확인일이 있는가
