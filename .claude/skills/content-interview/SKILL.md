# 콘텐츠 기획 인터뷰

새 콘텐츠 자동화 요청마다 사용자에게 기획 기준을 질의하고, 답변을 제작 입력으로 고정해 산출물에 반영한다. 질문지를 제시하는 데서 끝내지 않는다.

## 위치와 정본

스킬 폴더의 세 단계 상위가 위키 루트다. 현재 작업 디렉터리가 위키 루트인지 확인하고, 아니면 위치를 질문한다.

위키의 `CLAUDE.md`, 선택 제품 문서, 고객 가설, 톤앤매너, 승인 표현, 금지 표현, 관련 채널 문서를 읽는다. 레퍼런스는 채널 문서와 판독 문서로 찾고 선택한 원본 이미지도 직접 확인한다. 시각 확인 도구가 없으면 그 상태를 기록하고 구조 확인을 완료했다고 쓰지 않는다.

## 진행

1. [인터뷰 기준](references/interview.md)을 읽고 요청에 이미 있는 답을 추출한 뒤 미정 항목을 질문한다. 답을 기다리지 않은 채 그 선택에 의존하는 카피를 확정하지 않는다.
2. 상태는 `사용자 답변 / 기존 요청에서 확인 / 사용자에게 위임받은 추천 / 확인 필요`로 구분한다. 무응답·시간 경과·미제출 기본 선택은 답이나 승인이 아니다.
3. [브리프 서식](references/brief-template.md)으로 `deliverables/content/<건명>/00a_인터뷰기록.md`, `00_브리프.md`, `00b_요구사항반영표.md`를 작성한다. 개인정보를 제외하고 답변 요약과 적용 위치를 저장한다.
4. 필수 선택이 채워지면 요청 범위의 기획·근거 팩·카피·비주얼 브리프를 이어서 만든다. 선택된 상품·스토리·말투·구조를 다시 승인받지 않는다. 중요한 모호함만 구체적인 후보를 만든 뒤 해당 항목을 질문한다.
5. 제작에서는 위키의 researcher → copywriter → visual-director → brand-auditor 계약을 따른다. 역할은 사용 가능한 환경에서 순차 수행하거나 전달하며 동일한 브리프 경로와 버전을 사용한다. 서브에이전트 호출을 필수로 만들지 않는다.
6. 답변마다 실제 산출물 파일·장·슬롯·영상 시간의 반영 여부를 기록한다. 결과 경로와 미해결 항목을 보고한다.

새 캠페인의 필수 선택이 미확정인 예약·비대화 실행은 `인터뷰 대기`와 질문 목록까지만 남긴다. 이미 인터뷰한 브리프 재사용이 명시된 실행은 해당 범위에서 이어간다. 같은 캠페인의 후속 수정은 전체 인터뷰를 반복하지 않고 변경 항목만 기록·반영한다.

## 이벤트·혜택 기획

이벤트·기획전·할인/쿠폰·증정·댓글·체험 행사 요청이면 [조회수 기반 이벤트·혜택 기획](references/event-benefits.md)을 읽는다. 상품/목표·혜택 추천을 위임받으면 원본 조회수와 행사 자산을 연결해 후보·비용·운영 조건을 비교하고 추천안 및 페이지/팝업 제작으로 이어간다. 조회수를 전환 성과로 단정하지 않는다. 에이전트 기능 수정 요청에는 인터뷰를 새로 열지 않는다.

## 채널별 썸네일

썸네일·표지의 여러 디자인이나 채널별 A/B안 요청이면 [썸네일 변주 절차](references/thumbnail-variants.md)를 읽는다. 기존 브리프에서 채널별 방향·규격·고정 요소와 변경 범위를 정하고 후보표 → 실제 사진/확정 문구 합성 → 비교 미리보기·검수로 이어간다. 같은 캠페인은 새 전체 인터뷰를 열지 않는다.

## 숏폼 영상

릴스·쇼츠·틱톡 영상이면 [숏폼 영상 문법](references/short-form-video.md)을 브리프와 visual-director에 연결한다. 컷 구조를 사용자가 따로 정하지 않았으면 0.5~1.5초 컷의 속도감 있는 사용 장면이 기본이다. 3초 고정 컷을 기본값으로 쓰지 않는다.

## 누적 기준

사용자가 정한 기본안은 **새 스토리와 콘텐츠 세트 + 원본 말투 유지 + 원본 헤드·아래 서브·본문 구조 유지 + 고객 페르소나 반영**이다. 새 요청에서 이 기본안을 보여 주고 변경 여부를 묻는다. 핵심 카피를 원본 문장에서 가져올지(Q4-a)는 기본안과 별도로 매번 원본 후보 문장을 보여 주고 묻는다. 현재 요청에서 이미 이를 명시했으면 답변으로 기록한다. 이전 캠페인의 상품·콘셉트·수량·길이는 예시일 뿐 모든 캠페인에 강제하지 않는다.

## 경계

- raw 불변. 지식·승인 표는 사람 승인 없이 변경하지 않는다. 등록 대상은 승인된 표현이 아니다.
- 페르소나 가설을 검증된 VOC로 쓰지 않으며 다른 상품의 월령을 가져오지 않는다.
- 인터뷰 답변은 유료 생성·외부 발행·발송 승인과 별개다. 유료 생성은 위키 규칙에 따라 도구·수량·재시도 한도·비용을 구체화한 뒤 승인받는다. 이미 승인한 범위는 반복해서 묻지 않는다.
- 개인정보를 발견하면 위키의 중단·보고 규칙을 따른다. 개인정보 원문을 기록·카피·다른 역할에 옮기지 않고, 개인정보 없는 상태와 질문 목록만 반환한다. 근거·심의 문제와 2연속 FAIL도 위키의 중단 규칙을 따른다.
