# 인터뷰 결과 저장 서식

아래 서식을 실제 답변으로 채워 위키 루트의 `deliverables/content/<건명>/`에 저장한다. 개인 이름·연락처·계정·리뷰어 ID는 저장하지 않는다.

## 00a 인터뷰 기록

```markdown
# 기획 인터뷰 기록

- 캠페인:
- 기록일:
- 브리프 버전:
- 상태: 인터뷰 대기 / 필수 선택 완료

| 질문 ID | 질의 또는 현재 요청 | 개인정보를 제거한 답변 요약 | 상태 | 적용 위치 |
|---|---|---|---|---|
| Q1 | | | 사용자 답변 / 기존 요청에서 확인 / 사용자에게 위임받은 추천 / 확인 필요 | |

## 확인 필요와 다음 질문

- 항목 / 필요한 이유 / 영향을 받는 산출물:
```

- 핵심 이야기·메시지:
- 페르소나: 가설 또는 검증된 근거 표시
- 고객 관심·망설임:
- 인터뷰 기록 경로:
- 버전:

## 유지할 것과 바꿀 것

- 새 스토리·카피·장면:
- 유지할 말투·원본 예문:
- 영상 생성 방식 (Q7-a): text-to-video / Codex 첫 프레임 → image-to-video. 후자면 컷별 첫 프레임 프롬프트·저장 경로
- 핵심 카피 출처 (Q4-a): 원본 그대로 / 일부 변형 / 새로 작성. 슬롯별 채택 원문·원본 경로·발행 조건
- 유지할 헤드·아래 서브·본문 구조:
- 사용자에게 위임받은 추천:

## 채널별 구조 계약

| 채널·화면 | 수량·규격 | 기준 원본 경로 | 시각 확인 상태 | 위→아래 슬롯 순서 | 헤드 | 아래 서브 | 본문·강조 | 사진·배지 | CTA | 줄바꿈 |
|---|---|---|---|---|---|---|---|---|---|---|

없는 요소는 「없음」. 원본 없는 영상·메시지 본문은 「신규 제안」.

## 문장 근거와 고객 연결

| 채널·슬롯 | 문장 | 근거 경로·확인일·제품 정보 또는 유효한 C번호 | 페르소나 관심 | 원본 말투 |
|---|---|---|---|---|

## 00b 요구사항 반영표

```markdown
# 사용자 답변 반영표

| 질문 ID·답변 | 브리프 위치 | 실제 산출물 파일·장·슬롯·영상 시간 | 반영 / 미반영 / 확인 필요 | 이유·후속 작업 |
|---|---|---|---|---|

기획만 요청한 경우 기획 모듈을 연결한다. 미제작 이미지·미측정 영상에 최종 검수 PASS를 붙이지 않는다.
```

## 이벤트·혜택 요청 확장

`01_이벤트혜택기획.md`에 목표·상품·고객, 원본조회수 비교군(파일/시트/행/분모/총조회수/일평균/기간/유형/혜택/노출/누락), 후보 비교, 추천과 제외 이유, 비용 식·입력값, 운영 조건·일정, 미정값, 측정 계획을 기록한다. 숫자는 원본/계산/기획 제안/운영 확정으로 구분한다. 브리프에는 이 경로와 채택 후보·페이지/팝업 슬롯을 연결하고, 반영표에는 어떤 관찰이 어떤 선택을 바꿨는지 적는다.

## 썸네일 변주 요청 확장

`references/thumbnail-variants.md`의 후보표를 `thumbnails/기획.md`에 작성한다. 브리프에 노출 위치·채널 규격·방향 수·고정 요소·변경 허용 범위·확정 카피와 제품 사진 경로를 연결한다. 생성 배경 수와 최종 출력 수, 기존 승인 범위를 구분한다. 반영표는 각 후보 ID와 실제 PNG/JPG·preview.html·검수 상태를 연결한다.
