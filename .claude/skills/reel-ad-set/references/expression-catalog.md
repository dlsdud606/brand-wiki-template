# 영상 표현 방식 카탈로그 (레퍼런스 70편 → 유형별)

- 근거: 아동식품 브랜드 공개 릴스 70편 조사(2026-10-17)를 예시로 정리한 카탈로그. 업종이 다르면 aside 브라우저로 자기 업종 레퍼런스를 같은 형식(유형·조회수·게시 계정·영상 내용·링크)으로 조사해 `raw/reference-reels/`에 넣고 이 표를 다시 쓴다
- 쓰는 법: 레퍼런스에서 가져오는 것은 **유형과 영상 표현 방식(컷 구성·카메라·편집 리듬·사운드·자막 문법)** 뿐이다. 소재·스토리·카피·화면은 옮기지 않는다. 영상 내용은 자사 원본 자산의 카피에서만 나온다
- AI 품질은 Codex 첫 프레임 → image-to-video(5초 클립) 파이프라인 기준. 실사 촬영이면 이 열은 무시한다
- 조회수 천장은 70편 중 최고값. 수집 시점 표시값이며 노출 경로를 알 수 없으므로 유형 간 우열의 증거가 아니라 「그 유형에서 그 정도가 나온 적이 있다」는 뜻

## 2. 유형별 가져올 표현 방식

### A 제품 시즐·클로즈업
- 배경과 제품을 한 프레임에 두고 원재료를 곁에 배치하는 히어로 컷 (A-3, 7.9만)
- 질감 초근접 + 식감을 짧은 자막으로 받는 구조 (A-1·A-2, 9.8만·9.7만)
- 단일 동작 하나를 슬로로 끝까지 끄는 1컷 (A-9)
- 고속 촬영 질감의 액체 스플래시 (A-10)
- 사운드를 중심에 놓고 화면을 단순하게 두는 편집, 퀴즈형 자막 (A-8). 소리는 생성이 아니라 녹음·편집
- 가져오지 않음: 타사 제품 특성(치즈 늘어남, 바삭 식감 등)을 자사 제품에 억지로 대응시키기

### B 원료·산지·제조 신뢰
- 1인칭 현장 이동 시점, 원물에 손이 닿는 촉각 컷, 현장 자연광 (B-1, 379.3만)
- 공정 단계를 순서대로 나열하고 설비 클로즈업을 사이에 끼우는 구성 (B-4, 8.1만)
- 탑뷰 고정 프레임에 원재료를 한 컷씩 더해 가는 적층 편집 (B-8)
- 캐릭터가 산지를 찾아가는 B+F 결합 (B-10)
- 가져오지 않음: 창업자·농부 등장, 브랜드 스토리 내레이션
- **표기 의무**: 생성한 밭·공장은 자사 실제 현장이 아님 → 「우리 농장」·「직접 재배」·「계약 재배」·「산지 직송」·지역명 금지. 자막은 표시사항 원산지 사실만. 원산지가 국산이 아닌 원료의 장면에 국산 표기 금지. 상세페이지에 실제 공정 사진이 있으면 생성 대신 그 사진을 씀

### C 아이 먹방·리얼반응 (AI 불가 → 참여작·실사)
- 세로 원테이크로 현장을 그대로 포착 (C-2, 9.8만 — 같은 계정 다른 영상 1,396~1,836 대비. 고객 참여 영상) → 참여자 촬영 안내에 넣음
- 여러 명의 장면을 한 편에 모으는 연속 편집 (C-9)
- 크리에이터 공동 게시 (C-1, 143.4만)
- 가져오지 않음: 아이 얼굴을 생성으로 만들기, 평가·순위 매기기

### D 레시피·활용
- 과정을 순서 컷으로 끊고 손만 등장시키는 구성 (D-1·D-9)
- 측면 고정 컷으로 층이 쌓이는 과정 (D-3)
- 가져오지 않음: 자사 원본 자산에 없는 섭취 방식. 알레르기 표기가 걸리는 혼합 레시피
- **원본 확인**: 레시피 카피가 상세페이지에 있는지 먼저 찾는다. 있으면 원문 범위 안에서만

### E 상황극·스킷·밈 (AI 불가)
- 다큐 인터뷰 패러디처럼 포맷을 차용하는 자막 구조 (E-9)는 실사 제작 시 참고
- 가져오지 않음: 할인 콩트 (E-1·E-5. 구매 압박 금지 항목과 가까움)

### F 3D·AI·캐릭터
- 스톱모션 질감, 캐릭터와 제품의 스케일 대비 (F-1, 17.9만)
- 미니어처 스케일, 라인업을 공간에 배치하고 탑뷰로 훑는 이동 (F-3, 5.7만)
- 이동 수단을 축으로 공간을 전환하는 장면 연결 (F-8)
- 장치의 조작 화면을 그대로 영상 문법으로 쓰는 방식 (F-9)
- 번호를 붙인 에피소드 시리즈, 같은 오프닝 반복 (F-6·F-7, 3.8만·2.7만)
- 소재는 패키지 인쇄의 그림·캐릭터에서. 세계관을 새로 짓지 않음
- **별도 결정**: AI 생성 아기(F-4·F-5, 5.7만·4.9만)는 국내 실증 사례이나 얼굴 생성 정책은 위키 기준(얼굴 없음)을 따르고 사람이 바꾼다

### G 정보·전문가 (AI 불가 + 심의)
- 가져오지 않음. 전문가 권유는 `negative-list/forbidden-expressions.md` 전량 금지

## 3. 메타 광고로 옮길 때

- 릴스 MP4는 그대로 「인스타그램 릴스 동영상」 배치 소재. 안전 영역(위 14%·아래 35%·양옆 6%) 안에 자막·고지
- 정지 소재는 `channel-set` 템플릿: `meta_feed_product`·`meta_feed_benefit`·`meta_feed_info`(1440×1800), `reel_endcard`(1080×1920). 릴스 누끼·생성 배경은 `import-reel`로 재사용
- 광고 문구 길이: primary_feed 125자 · primary_reel 44자 · headline 27자 (`05_channels/meta-ads.md`)
- 행동 유도 버튼은 이미지 안에 그리지 않음. 할인율을 쓰면 기간·정가·할인가 병기
- 생성 자산 고지(「AI 생성 연출」·「패키지 이미지 예시」)는 광고에서도 지우지 않음
